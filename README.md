# Image to PDF

Image(s) to PDF converter.

Generated this app in 10 minutes (vibe coding) using [v0](https://v0.dev), with the following prompt:

> "Create a React app that allows the user to input one or more images, and combine them into a PDF when pressing a button.  
> Maintain the aspect ratio of each image. You can use the latest Next, shadcn and Tailwind versions."

## Try it Here
👉 [Live Demo](https://v0-img-to-pdf.netlify.app/)

## How to Run

1. Clone the repository, install dependencies and run locally:
   ```bash
   git clone https://github.com/mihai10001/img-to-pdf.git
   cd img-to-pdf
   npm install
   npm run dev
   ```

2. Or build:
   ```bash
   npm run build
   ```
